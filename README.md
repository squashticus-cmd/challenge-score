# 🏆 Challenge Score

**Marcador de puntuación profesional para 8 deportes de raqueta**

Desarrollado por **Squashner** · Versión **Taro 0.6.0**

## 🎾 Deportes soportados

| Deporte | Modalidad |
|---------|-----------|
| 🎾 Tenis | 0/15/30/40, tie-break, mejor de 3/5 sets |
| 🥇 Squash | PAR 11, win by 2, mejor de 5 sets |
| 🎾 Pádel | 6 games, tie-break, mejor de 3 |
| 🏸 Badminton | A 21, win by 2, tope 30 |
| 🥒 Pickleball | A 11, win by 2, mejor de 3 |
| 🎱 Raquetbol | A 15, win by 2, mejor de 3 |
| 🥎 Frontón | A 22 puntos, set único |
| 🏓 Tenis de Mesa | A 11, win by 2, cambio de saque cada 2 |

## ✨ Características

- 📱 **100% offline** — sin nube, sin servidores
- 🎯 **Responsive** — móvil, tablet, desktop
- 💾 **Datos locales** — historial en el dispositivo
- 📤 **Compartir** — WhatsApp, nativo, imprimir/PDF
- 🎨 **Diseño profesional** — escudos y colores por deporte
- 🆓 **Sin costo** — herramientas gratuitas

## 🛠️ Stack técnico

- HTML5 + CSS3 + JavaScript vanilla
- Sin frameworks, sin dependencias
- PWA instalable
- Empaquetable a Android/iOS
